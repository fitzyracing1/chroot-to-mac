# chroot-to-mac

A how-to for connecting [chroot](https://github.com/fitzyracing1/termux-app),
Joshua Almeida's Termux fork for Android, to a Mac over SSH.

The full step-by-step guide is in the pull request from the `docs/workflow`
branch. After that pull request is merged, this README will be replaced by the
complete walkthrough.
